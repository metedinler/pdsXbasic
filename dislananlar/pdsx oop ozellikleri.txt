## ?? 4. Detaylý OOP Özellikleri ve pdsX Uyarlamasý

### ? 4.1 Kapsülleme (Encapsulation)

**Amaç:** Deðiþkenlerin doðrudan deðil, fonksiyonlar aracýlýðýyla eriþilmesi.

```basX

    FUNC setIsim(x)

    ENDFUNC

```

### ? 4.2 Kalýtým (Inheritance)

**Amaç:** Davranýþlarý tekrar yazmadan alt sýnýflara miras vermek.

```basX

    FUNC hareketEt()
        PRINT "Arac hareket ediyor"
    ENDFUNC

    FUNC korna()
        PRINT "Bip bip!"
    ENDFUNC
ENDCLASS
```

```basX

CALL a.hareketEt()

```

### ? 4.3 Çok Biçimlilik (Polymorphism)

**Amaç:** Ayný fonksiyon adý farklý sýnýflarda farklý çalýþabilir.

```basX

    FUNC alan()
        RETURN 0
    ENDFUNC
ENDCLASS

    VAR kenar
    FUNC alan()
        RETURN @kenar * @kenar
    ENDFUNC
ENDCLASS
```

```basX

SET s.kenar = 4
PRINT CALL s.alan()  ; 16
```

### ? 4.4 Soyutlama (Abstraction)

**Amaç:** Sadece arayüz tanýmlanýr, iç detay alt sýnýflarda tanýmlanýr.

```basX

ENDCLASS
```

Alt sýnýflar bu metodu **zorunlu olarak** implement etmek zorundadýr.
